# Team Portfolio Website

## Project Brief
Team Portfolio Website merupakan website yang dikembangkan
untuk memperkenalkan identitas kelompok, menampilkan
profil setiap anggota, serta mendokumentasikan proyek
yang telah dikerjakan oleh anggota tim.

Website ini bertujuan memberikan informasi mengenai
kemampuan, keahlian, pengalaman, dan hasil pekerjaan
tim kepada pengunjung atau calon kolaborator.

## Project Objectives
- Memperkenalkan identitas dan anggota tim.
- Menampilkan kumpulan proyek yang telah dikerjakan.
- Memberikan informasi detail mengenai setiap proyek.
- Memudahkan pengunjung menghubungi anggota tim.

## Requirements

### Functional Requirements
1. Website menampilkan halaman Home.
2. Website menampilkan profil anggota tim.
3. Website menampilkan daftar proyek.
4. Pengunjung dapat melihat detail setiap proyek.
5. Website menyediakan informasi kontak tim.
6. Pengunjung dapat mencari atau memfilter proyek.
7. Website mengambil data melalui API.

### Non-Functional Requirements
1. Website memiliki tampilan responsif.
2. Navigasi website mudah dipahami.
3. Tampilan konsisten pada setiap halaman.
4. Website dapat diakses melalui browser modern.
5. Website memiliki performa dan accessibility yang baik.

## Minimum Technical Requirements
- Reusable Components
- User Flow
- State Management
- API Integration 
- Unit Testing / Function Testing
- Git dan GitHub
- GitHub Projects
